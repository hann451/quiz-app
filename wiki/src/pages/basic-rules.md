## 3年モード（公式仕様）と「3年縛り」の違い

今作（2026-2027版）から公式機能として実装された「3年モード」（正式名称：3年モード〈目指せ甲子園！〉）と、コミュニティで従来から行われてきた自主ルール「3年縛り」は別物です。

### 公式「3年モード」の仕様

| 項目 | 内容 |
|---|---|
| **モード概要** | 通常モードとは別に、3年間（1年目春〜3年目夏）に限定して甲子園優勝を目指す新モード <!-- actions-test --> |
| **試合形式** | 3年モード中の試合は「戦術試合」のみに固定（その他の試合スタイルは選択不可） |
| **難易度** | 「世間の注目」による難易度上昇要素は通常モードのみに存在し、3年モードには無いため難易度は低めとされる |
| **通常モードへの移行** | 3年目の夏の大会終了後、育成したチーム・データを引き継いだまま通常モードに移行してプレイを継続可能 |
| **アイテム持ち込み** | パワプロショップ購入アイテムやオンラインプレゼントのアイテムは**3年モードには持ち込み不可**（例外：にじさんじコラボ履歴書のみ持ち込み可） |
| **その他の制限** | OBログインボーナスやプロ野球選手図鑑登録人数ボーナスのイベントも通常モードのみで発生 |
| **セーブデータ** | 今作からセーブデータを5個まで保存可能（前作までは1個のみ） |
| **新入生の転生選手枠** | 前作までは1学年最大3人までだったが、今作は**1学年最大4人**（にじさんじコラボ転生は別枠でさらに4人まで、合計最大8人も可能） |

### コミュニティ通例「3年縛り」との違い（自主ルール、非公式）

以下は、公式仕様ではなくプレイヤーコミュニティで従来から行われている自主ルール・ローカルルールの例です。ゲーム側の強制力はありません。

| 自主ルールの例 | 内容 |
|---|---|
| **育成期間の定義** | 1年目4月〜3年目夏の甲子園終了、または1年目新入生の引退までを1セットとする |
| **リセマラの自主制限** | リセマラは3回まで、ただし転生プロ/OBが出ない場合は出るまで可、等の個人ルールを設定するプレイヤーが存在 |
| **アイテム持ち込み禁止** | 「魔物」「天才肌持ち込み」「アイテム」「卒業生」を禁止して1年目をプレイする、といった動画企画も存在 |

## 新入部員の選び直し（3回まで）の詳細

2026-2027版の今作全体（通常モード・3年モード共通）の新機能として、1年目のみ新入部員（新入生）の選び直しが**3回まで再抽選可能**になりました（旧作ではソフト再起動が必要でした）。

| 項目 | 内容 |
|---|---|
| **手順（要約）** | ①出したい転生OBの都道府県・年代を決める → ②「転生選手の登場」を「あり」に → ③新入部員画面で候補を確認 → ④気に入らなければ再抽選（最大3回） → ⑤3回を超えて狙いの選手が出ない場合はホーム画面に戻り最初からやり直す |
| **注意点** | 新入部員画面まで進んだ後は前の画面（都道府県・年代選択）には戻れない。学校名等の設定は再抽選しても維持される。 |

※ セーブデータとの関係: 複数セーブデータを作成できるようになったが、これは「好きなタイミングでやり直せる」という意味ではなく、正しい手順で終了しなかった場合は従来通りペナルティが発生します。

## 年代ループ（西暦指定）の仕組みとリセマラ手順

| 開始方法 | 選択できる項目 | 手順概要 |
|---|---|---|
| **現代開始** | 都道府県のみ（年代は自動で現在に固定） | ①目当てのOBが出る都道府県に設定 → ②「転生選手の登場」を「あり」に → ③新入部員を確認、③回まで再抽選可能 |
| **過去スタート** | 年代（西暦）＋都道府県の両方 | ①入学式直前にセーブ → ②「はじめから」で年代設定し「上の方の1年」を確認 → ③目当てでなければホームへ戻り再試行 → ④目当てなら「つづきから」で入学式へ進む |
| **年代の狙い方(応用)** | スカウト候補年代 ＝ 目当て選手の転生年代の前年になることが多い | 例：山田久志(1964年転生)を狙う場合、スカウト候補年代は「1963年」に設定 |

## DH制・大谷ルールの設定方法

今作（2026-2027）で新規実装された機能です。

| 項目 | 内容 |
|---|---|
| **DHとは** | 投手に代わって打撃のみを行う攻撃専門の選手。投手は打撃をする必要がなくなり、DH起用選手は守備につく必要がなくなる。 |
| **大谷ルール(二刀流)の設定手順** | ①オーダー設定画面でレギュラー最下部の「P」（先発投手）を選択 → ②選択した投手を「DH」の選手にカーソルを合わせ「先発&DH」を選択 → ③DHと先発投手に同一選手が出力され二刀流が適用される |
| **大谷ルールの効果** | 先発投手がDHを兼任し、降板後もDHとして打席に立ち続けられる（投手交代後も打者として出場を継続） |
| **プレー上の注意点** | 大谷ルール適用選手を「注目選手」に設定すると投手・野手両方の操作機会が発生する。ピンチの多い試合展開だと投手としての操作ばかりになり打席に立つ機会が減る傾向がある。 |

## ライバル校編集機能

| 項目 | 内容 |
|---|---|
| **ライバル校情報の確認** | 対戦したことのある学校との通算勝敗、戦力（オーダー等）を確認できるように。 |
| **ライバル校の編集** | ライバル校の高校名・ユニフォームを自由に編集可能。 |
| **ユニフォーム編集の強化** | ラインタイプがA/Bの2種類に分かれ、Aだけで約30種類程度に増加。プリセットも使用可能に。 |
| **高校名・都道府県・年代の変更タイミング** | 高校名はメニュー「データ→登録設定→高校名・よびかた設定」からいつでも変更可能。ただし「年代設定」と「都道府県」は入学式のタイミングでしか設定できない（転生OBの登場条件に直結するため）。 |
| **進級時の都道府県変更** | 4月の新年度（進級）タイミングで「継続する（データ・選手を維持して都道府県変更）」か「継続しない（新都道府県で新監督として開始、元のチームは他校として登場する可能性）」を選択可能。 |
