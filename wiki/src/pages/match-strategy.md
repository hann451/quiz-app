## 試合指示の基本と「信頼度」

栄冠ナインの試合は基本的にオートで進行し、プレイヤーは要所で「戦術アイコン」を選択して選手に指示を出します。この際、アイコンに表示される数字（戦術レベル：1〜7）が大きいほど、指示が成功する確率が高まります。

戦術レベルは選手の能力値だけでなく、**「信頼度」**と**「調子」**、そして**「大応援（連打時などのチームバフ）」**に大きく依存します。
特に戦術レベルごとの成功率・期待値は右肩上がりに上昇するため、常に高い数字を選ぶことが勝率に直結します。

### 戦術レベル(1〜7)の成功率・期待値の目安
*   **レベル1〜3**: 凡退リスクが高く、戦術が意図通りに機能しないことが多い。
*   **レベル4〜5**: 基本的な上限ライン。能力と信頼度が育ってくると安定して出せるようになり、ヒットや出塁を十分に期待できる。
*   **レベル6**: 特定の青特（例：アベレージヒッター、内野安打◯など）を持っている場合や、大応援発動時に出現。**成功率が跳ね上がるボーダーライン**。
*   **レベル7**: 絶好調＋高信頼度＋対応する青特など、複数の条件が重なった時にのみ出現する最高レベル。**圧倒的な成功率・出塁率を誇り、出た場合は最優先で選ぶべき数字**。

![信頼度イメージ](https://img.game8.jp/12641762/ffae1072a6f2aee3b6f58d02553a3018.webp/show)

| 信頼度の上げ方 | 詳細・効果 |
|---|---|
| **試合に出場させる** | 最も効率的な上昇方法。スタメンでなく[途中出場](#途中出場代打代走による経験値稼ぎパリコレ)でも上がる |
| **指示を出す** | 「おまかせ」よりも、具体的な戦術（転がせ、等）を指示した方が上がりやすい |
| **イベントマス** | 卒業生のアイドルや特定の青マスイベント、進路相談、食事会イベントなどで上昇 |
| **信頼度の効果(数値補正)** | 信頼度が一定値を超えるごとに、戦術レベル（数字）の基礎値に **+1〜+2のプラス補正** がかかります。本来の能力が低くても数字が高くなりやすいため、非常に重要です。 |

出典: [appmedia.jp](https://appmedia.jp/pawapuro2026-2027/), [game8.jp](https://game8.jp/eikan-nine/)

> 実践への活かし方: 3年縛りでは初期の信頼度が低いため、初年度の試合は苦戦必至です。秋の大会や練習試合では、たとえ負け試合でも下級生を積極的に代打・代走で出場させ、来季に向けた信頼度稼ぎを優先しましょう。

## 打撃指示の特徴と最強戦術「転がせ」

打撃時の戦術アイコンは、状況と選手の能力によって使い分ける必要がありますが、迷った時の最適解が存在します。

![打撃指示イメージ](https://img.game8.jp/10278503/c442dfc3e6e90b3a140f05eada03f20e.png/show)

| 打撃指示 | 特徴と有効な場面 | 依存する能力 |
|---|---|---|
| **転がせ** | **栄冠ナイン最強戦術。**ヒットになる確率が極めて高く、迷ったらこれ。 | ミート、走力、内野安打◯ |
| **流し打ち** | 「転がせ」に次いで安定する戦術。右打ちを狙いたい場面で有効。 | ミート、広角打法、流し打ち |
| **引っ張り** | 長打を狙う戦術。ゲッツー崩れなどを期待できるが凡退リスクも高い。 | パワー、プルヒッター |
| **センター返し** | 安定してヒットを狙える。ピッチャー返しによる内野安打も。 | ミート、アベレージヒッター |
| **犠牲フライ** | ノーアウト・ワンアウト3塁での確実な得点源。 | パワー、弾道 |
| **送りバント** | 確実な進塁手段。[バント職人](/wiki/card-effects)があると戦術Lvが跳ね上がる。 | バント能力 |

出典: [game8.jp](https://game8.jp/eikan-nine/), [kamigame.jp](https://kamigame.jp/)

### 「魔物」の活用について
性格が「内気」の選手が持つ固有戦術「〇〇の魔物」は、相手のエラー率を極端に跳ね上げる強力な戦術です。打撃戦術「転がせ」と組み合わせることで、エラーによる大量出塁・大量得点が狙えます。詳細は[性格と固有戦術](/wiki/personalities)を参照してください。

> 実践への活かし方: 基本は「戦術レベルの高いものを選択」ですが、レベルが同じであれば「転がせ」を優先します。特に相手の守備力が低い地方大会序盤では、「転がせ」による内野安打や送球エラーで一気に崩すことができます。

## 投球指示の特徴と注意点

投球時の指示は、抑える確率を上げるだけでなく、投手の育成（獲得経験値）や赤特付与のリスクにも関わります。

![投球指示イメージ](https://img.game8.jp/12643542/118b78c3775d296c010266199cf04e43.webp/show)

| 投球指示 | 特徴と有効な場面 | リスク・注意点 |
|---|---|---|
| **低め中心** | 長打（ホームラン）を防ぎ、ゴロを打たせやすい。基本戦術。 | - |
| **内角中心** | 詰まらせて凡打を狙う。 | コントロールが低いと死球のリスクあり |
| **緩急重視** | 直球と変化球を織り交ぜて空振りを狙う。変化球の経験値が入る。 | - |
| **クサイところ** | ストライクゾーンぎりぎりを狙う。レベルが高いと強力。 | 四球のリスクあり |
| **1球はずせ** | 相手のスクイズ警戒や、カウントを悪くして凡打を誘う。 | **多用すると赤特「四球」がつくリスク大** |

出典: [note.com](https://note.com/), [appmedia.jp](https://appmedia.jp/eikan_nine/)

> 実践への活かし方: 「1球はずせ」は便利ですが、使いすぎると「ボール先行」や「四球」といった致命的な赤特がつく原因になります。戦術レベルが高い「低め中心」や「緩急重視」を中心に組み立てるのが安全です。

## 伝令の効果と使用タイミング

試合中にベンチから「伝令」を送ることで、ピンチを脱したりチャンスを広げたりすることができます。伝令の効果は送る選手の[性格](/wiki/personalities)によって異なります。

![伝令イメージ](https://img.game8.jp/12641762/ffae1072a6f2aee3b6f58d02553a3018.webp/show)

| 性格 | 伝令名 | 伝令効果 |
|---|---|---|
| **熱血漢** | 盛り上げる | チーム全員のパワーUP |
| **クール** | 助言する | チーム全員のミートUP |
| **お調子者** | 励ます | チーム全員のテンション（調子）UP |
| **内気** | なだめる | 投手のスタミナ回復 |
| **したたか** | ホメる | 投手の球速・コントロールUP |

### 伝令のボーナス仕様
- **キャプテンボーナス**: キャプテンを伝令に出すと、自身の性格の効果に加えて**他の性格の効果がランダムで1つ上乗せ**されます。
- **学年ボーナス**: 伝令に出た下級生は試合経験値と信頼度を獲得できます。

出典: [game8.jp](https://game8.jp/eikan-nine/)

> 実践への活かし方: 試合序盤〜中盤で点差が開いていない場面で、熱血漢やクールの伝令を使い、チーム能力を底上げして主導権を握るのがおすすめです。また、スタメン落ちしたキャプテンは最強の伝令役としてベンチに置いておく価値があります。

## 盗塁判断の基準値

栄冠ナインでは戦術として「盗塁」を指示できますが、無謀な盗塁はチャンスを潰すだけです。以下の基準を満たしているか確認しましょう。

![盗塁イメージ](https://img.game8.jp/12641762/ffae1072a6f2aee3b6f58d02553a3018.webp/show)

| 判断要素 | 盗塁を推奨する目安 |
|---|---|
| **走力** | **C以上**（B以上ならかなり安定） |
| **特殊能力** | [盗塁◯、盗塁A、電光石火](/wiki/card-effects) 等がある |
| **戦術レベル** | **レベル5以上** |
| **相手捕手の肩力** | D以下（C以上の強肩捕手相手はリスク増） |

※ **三盗（2塁から3塁への盗塁）は原則行わない**仕様/セオリーとなっています。リスクとリターンが合わないため、指示は控えましょう。

出典: [saiseikojo.com](https://saiseikojo.com/), [note.com](https://note.com/)

> 実践への活かし方: 自動進行中にもCPUが勝手に盗塁を試みることがあります。これを防ぐためにも、走力C未満の選手は極力出塁させない（または即代走を送る）か、相手の隙を突ける走力B以上の機動力チームを作り上げるのがポイントです。

## 途中出場・代打・代走による経験値稼ぎ（パリコレ）

試合に出場した選手は、試合終了後に大きな経験値と信頼度を獲得します。これを活かしたベンチメンバーの育成テクニックが通称**「パリコレ」**です。

![パリコレ交代イメージ](https://img.game8.jp/12643543/0f0a6f11311b78d46ac1626db6619bd2.webp/show)

| 状態 | 獲得経験値の目安 |
|---|---|
| **スタメンフル出場** | 最大 |
| **途中出場（代走・守備固め）** | 大（ベース約900〜） |
| **途中出場（代打）** | 中（ベース約450〜） |
| **ベンチ入り（未出場）** | 小 |
| **ベンチ外** | ほぼ無し |

### パリコレ（全員出場）のやり方と注意点
大差で勝利が確定している9回表・裏などで、ベンチメンバーを次々と代打・代走・守備交代で出場させます。これにより、本来試合に出られない下級生にも出場経験値と信頼度を付与できます。

**【重要仕様・アップデートの注意点】**
近年のアップデートや最新作の仕様では、**「1打席が完了しないと出場扱い（経験値付与）にならない」**など、交代枠の消費だけで経験値が入る仕様が厳格化されているケースがあります。打席の途中で代打の代打を出したりせず、しっかりと1プレイを完了させるようにしてください。

出典: [appmedia.jp](https://appmedia.jp/pawapuro2026-2027/), [youtube.com](https://www.youtube.com/)

> 実践への活かし方: 3年縛りでは新入生の成長スピードが命です。秋の地方大会や練習試合などで点差が開いたら、1年生を片っ端から代打・代走で出場させ、少しでも経験値と信頼度を稼いでおきましょう。
