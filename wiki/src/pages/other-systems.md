## 学校の評判システム

栄冠ナインでは、公式戦の勝利数とチームの注目度（世間の注目）によって「評判ゲージ」が上昇し、評判ランクが上がります。評判が上がると様々な恩恵を受けられます。

### 評判の段階と各段階の恩恵（2026-2027版）

| 評判 | グラウンド色 | 進行アイコン数 | 入部者数（投手内訳） | ドラフト人数 | スカウト範囲 |
|---|---|---|---|---|---|
| **弱小** | 白 | 4 | 6人（投手2） | 1人 | 所在都道府県 |
| **そこそこ** | 白 | 5 | 7人（投手2） | 2人 | 所在都道府県 |
| **中堅** | 白 | 6 | 8人（投手2） | 3人 | 所属地区 |
| **強豪** | 黒 | 7 | 9人（投手3） | 4人 | 所属地区＋隣接地区 |
| **名門** | 黒 | 8 | 10人（投手3） | 5人 | 全国 |
| **超名門** | 黒 | 9 | 10人（投手3） | 7人 | 全国 |

※「超名門」は2026-2027版で新規追加された最上位評判ランクです。条件は「甲子園3連覇（3年連続優勝）」とされています。

### ボランティアの効果
「ボランティア（球拾い等）」アイコンは評判ゲージを直接上げる効果がありますが、段階（ランク）自体を一段跳びに上げるものではなく、弱小～そこそこの間のみ使用可能で年2回までという制限があります。

## 卒業生の就職先とマス効果

卒業生（OB）は、在学時の成績や能力に応じて様々な職業に就き、OBマスに止まった際にチームに恩恵をもたらします。

| 就職先 | マス効果 | 評価目安 |
|---|---|---|
| **アイドル** (女子マネ限定) | 練習効率アップ or テンションアップ | S評価 (最高クラス) |
| **本屋** | 特殊能力本をもらえる | S評価 (非常に高価値) |
| **プロ野球選手** | 赤特消去(確率) / 練習経験値アップ / 練習効率ダウン / 黄色マス化 のいずれか1つ | A評価 |
| **占い師** | 性格をランダム変更 or 数日先のマスをランダム変更 | A評価 |
| **ミゾット社員** | 練習器材交換券 / 耐久度アップ | A評価 |
| **スカウト** | スカウト評価アップ or 新入生の履歴書入手 | B評価程度 |
| **職人** | 能力上昇アイテム入手 | B評価程度 |
| **サラリーマン** | 学力アップ（2人まで） | C評価程度 (学力用途限定) |
| **看護師** (女子マネ限定) | 体力回復 | C評価程度 |
| **ならずもの** | スケジュールアイコンを全て入れ替え | 用途限定 (ハイリスク) |
| **肉屋/魚屋/八百屋/パン屋** | 各経験値アップ（低確率で+5） | 下位評価 |
| **ショップ店員** | アイテム入手 | 下位評価 |
| **大学生 / 社会人野球選手** | 個別の具体的マス効果は本調査で確認できませんでした | 未確認 |

※ 就職先とマス効果の対応関係については、概ね過去作やモバイル版と一致していますが、コンソール版「栄冠ナイン」特有の細部の数値・確率は異なる可能性があります。

## アイテム（本・道具）の効果一覧

### 性格変更・特殊能力本

| アイテム名 | 効果 | 入手方法 |
|---|---|---|
| **自分探しの本** | 性格をランダムに変更（「天才肌」には変化しない） | 戦績ショップで400P |
| **各種特殊能力本（金特本）** | 該当の金特を選手に付与 | 春・夏の甲子園抽選会翌日（3/14・8/3）にOB/白マスのランダムイベントで入手、または5勝ごとの行商人（新規）から購入 |
| **参考書** | 学力関連の効果（詳細未確認） | 戦績ショップで400P |

### 占い師イベント
- 卒業生（OB）の就職先の一つで、進行マップ上に**キャラクターマス**として登場します（白マスを踏んだ際に確率で出現するわけではありません）。
- 「選手の性格について」: 選手の性格をランダムに変更（「天才肌」への変化はなし）
- 「チームの未来について」: 数日先までの予定マス（青・赤・黄）をランダムに変更
- **【注意】** 旧版にあった「白マスを踏んだ際に約5%〜10%の低確率で出現する」という情報は誤り（俗説）です。占い師を含む全てのOBはマスとして出現します。

### 優勝旗アイテム
- 春の甲子園優勝で【紫紺の優勝旗】、夏の甲子園優勝で【深紅の優勝旗】を入手します。
- **効果**: 優勝旗の所持中に白マスを踏んだ際、【低確率】で「テンションアップ」「練習効率アップ」「疲れの回復」「特殊能力の獲得」のいずれかが発生します（旧版の「約25%〜30%の高確率」は誤りの可能性が高い数値です）。
- **返還**: 獲得した優勝旗は、次の同じ季節の甲子園で返還します。

## グラウンドレベル補正倍率

| ■ 基本仕様と計算ロジック |  |  |
|---|---|---|
| 補正の計算（重要な訂正） | グラウンドレベルは初期値1で、1レベル上がるごとに練習経験値へ約+0.5%のボーナスがつく連続的な補正です。旧版の「Lv区分ごとに1.00倍〜1.60倍の階段表」「白土=Lv1〜29／黒土=Lv30〜122」という対応関係は、確認できるデータには存在しません。 |  |
| Lv99での効果 | レベル1とレベル99では練習経験値に約1.5倍の差（＝約+49%）があるとされています。2024-2025での検証では、機材を全種そろえ土を最大にしてもLv99表記で補正は+49%で打ち止めでした。 |  |
| 今作のレベル上限（新要素） | 従来は上限99でしたが、今作（2026-2027）では99を超えて解放されるようになりました。評判が超名門の場合に上限122まで解放されることが確認されています。名門では119程度が上限という報告もあります。※99超の領域で補正が+0.5%/Lvのまま伸び続けるかは未検証です。 |  |
| 白土・黒土について | 黒土は評判が強豪以上で解放される要素で、グラウンドレベルの上昇と黒土専用アイテムの使用が可能になります。ただしレベル帯と土の種類が固定で対応しているわけではありません。 |  |
| レベルの上げ方 | 主に①ショップ（5勝ごとに利用可）での練習機材の購入・設置、②グラウンドの土の購入、③白マスのミゾット社員イベント（機材の入手・メンテナンス）で上昇します。グラウンドレベルの大部分は機材が占めるため、まず1000ポイントの機材を全種そろえ、その後にお楽しみ交換券を使うと効率的（そろえた後は2000ポイント機材のみが出るようになるため）。土は耐久値が低くコスパが悪いので機材を優先。 |  |
| レベルが下がる要因 | 機材は使用するたびに劣化し、壊れるとグラウンドレベルが下がります。耐久値は「設置」画面から確認できるので、壊れそうなものは事前に交換券を確保しておくと安全です。練習でレベルが下がった場合は「下がった後の数値」で経験値が計算されるため、上限を維持したいなら土で多めに余裕を持たせておくのが有効です。 |  |
| その他の経験値変動要因（参考） | 体力：最大(5)は体力1の約1.2倍。天候：雨・雪の日は約0.6倍。これらもグラウンドレベルと同様に日々の獲得経験値へ影響します。 |  |
| ■ グラウンドレベル × 練習経験値補正の目安 |  |  |
| グラウンドレベル | 経験値補正の目安 | 備考 |
| Lv 1 | +0%（基準） | 初期状態 |
| Lv 20 | 約 +9.5% | 機材を数点そろえた段階 |
| Lv 50 | 約 +24.5% | 機材が一通りそろってくる段階 |
| Lv 99 | 約 +49%（約1.5倍） | 従来作の上限。まずここの維持が目標 |
| Lv 100〜122 | 未検証（今作で解放された領域） | 評判が超名門で122まで解放を確認。補正の伸び方は未検証 |
| ※補正値は「1レベルにつき+0.5%」という2024-2025での検証結果に基づく計算値です。今作でLv99超の領域まで同じ係数が続くかは未検証のため、Lv100以降は目安を記載していません。 |  |  |

## マネージャーと進路仕様

| ■ 仕様の訂正と基本ルール |  |  |
|---|---|---|
| 男子マネージャーも存在する（重要な訂正） | マネージャーは女子だけではなく【男子マネージャー】も存在します。旧版は「女子マネージャーが自動で入部する」前提で書かれていましたが、男マネが来る場合もあります。 |  |

| マネージャー評価という仕組みは確認できず（重要な訂正） | 旧版の中心だった「マネージャー評価（信頼度）を公式戦の勝利や合宿提案の受諾で上げると、差し入れの質が上がり上位進路に就職しやすくなる」という仕組みは、確認できる攻略情報に該当する記載がありませんでした。進路も「最終評価値×チーム評判×ランダム抽選」ではなく、確率で決まるものと説明されています。 |  |

| 入部タイミング | スカウト成功後、4月の入学式で新入生としてチームに加入します。 |  |  |
| 同時加入 | 4名を同時に入学させることも可能です。ポジションも被らない構成になっています。 |  |  |
| 他モードでの使用 | コラボライバーは栄冠ナインだけでなく、対戦モードやペナントなど他モードでも使用できます。 |  |  |
| 性格・所持特能について | 旧版が記載していた各キャラの確定性格（内気・クールなど）と確定所持青特は、いずれも実在しないキャラを含むため全て無効です。実際の4名は初期能力が高く金特を所持しているとの情報がありますが、個別の性格・特殊能力の詳細はゲーム内のステータス画面、または各キャラの攻略ページで確認してください。 |  |  |
