## 卒業生の就職先と効果

栄冠ナインでは、3月に卒業した3年生が様々な職業に就職し、その後OB・OGマスに止まった際にチームへ恩恵をもたらしてくれます。

![卒業生就職先イメージ (出典: https://img.game8.jp/12643542/118b78c3775d296c010266199cf04e43.webp/show)](/images/other-systems/118b78c3775d296c010266199cf04e43.webp)

| 職業 | マスに止まった際の効果 | 優先度 |
|---|---|:---:|
| **アイドル** | 選手数名のテンションUP、新入生の履歴書入手、**練習効率UP** | ★★★ |
| **本屋** | [特殊能力（青特・赤特消しなど）](/wiki/card-effects)の本をもらえる | ★★★ |
| **ミゾット社員** | 練習器材の提供、または壊れた器材の修理 | ★★★ |
| **プロ野球選手** | 練習経験値UP、または赤特のランダム消去 | ★★☆ |
| **スカウト** | 「新入生の履歴書」を入手しやすい | ★★☆ |
| **占い師** | 選手の[性格](/wiki/personalities)を変更できる | ★★☆ |
| **ならずもの** | 進行アイコン（スケジュールカード）をシャッフルする | ★☆☆ |

出典: [appmedia.jp](https://appmedia.jp/pawapuro2026-2027/), [game8.jp](https://game8.jp/eikan-nine/)

> 実践への活かし方: 女子マネージャーは高確率で「アイドル」に就職します。アイドルマスは練習効率を上げる最強クラスのマスなので、マップ上に見つけたら最優先で踏みにいきましょう。

## 評判とテンション

チームの「評判」と選手の「テンション」は、チームの地力を底上げする重要なパラメータです。

![評判テンションイメージ (出典: https://img.game8.jp/12641771/8680631c5f03de4b035d239220a2887d.webp/show)](/images/other-systems/8680631c5f03de4b035d239220a2887d.webp)

### 学校の評判の恩恵

評判は公式戦で勝利する（または大会を勝ち進む）ことで上昇します。逆に、初戦敗退や非公式リセット（ペナルティ）で低下します。

| 評判ランク | 恩恵・メリット |
|---|---|
| **弱小 / そこそこ** | 特になし（スタートライン） |
| **中堅** | 入部希望者が増加し始める。スカウト可能地域が広がる |
| **強豪 / 名門** | ドラフト指名枠が増加。進行アイコンの選択肢が増える |
| **超名門** | **進行アイコンが9個に増加**。グラウンドレベル大幅上昇、特訓マス効果UP |

※「超名門」は最新作で追加された最高ランクです。条件は**甲子園で3期連続優勝**と非常に厳しいですが、圧倒的な恩恵があります。

### テンション（調子）の管理

テンションは試合での能力（打撃結果や投球の安定感）に直結します。

- **テンションの上げ方**: アイテム「お褒めの言葉」を使う、白マスでのランダムイベント、アイドルマスの効果、公式戦での勝利。
- **キャプテン効果**: [性格](/wiki/personalities)が「お調子者」の選手をキャプテンにすると、白マスイベント等でチーム全体のテンションが上がりやすくなります。

出典: [yahoo.co.jp](https://games.yahoo.co.jp/), [saiseikojo.com](https://saiseikojo.com/)

> 実践への活かし方: 3年縛りでは時間が無いため、アイテム「お褒めの言葉」は出し惜しみせず、大事な公式戦の直前にスタメンのテンションを強引に引き上げるために使い切りましょう。

## 転生OB・転生プロの仕組みとスカウト

特定の条件を満たすと、実在のプロ野球選手や往年の名選手（転生OB）が新入生として入学してきます。

![転生OBイメージ (出典: https://img.game8.jp/10278503/c442dfc3e6e90b3a140f05eada03f20e.png/show)](/images/other-systems/c442dfc3e6e90b3a140f05eada03f20e.png)

| スカウト方法 | 詳細・仕様 |
|---|---|
| **年代ループ（ゲーム開始時）** | ゲーム開始時の設定で、狙いたい転生選手が高校1年生だった年代と[都道府県](/wiki/prefectures)を設定する。 |
| **新入生スカウト** | 11月以降のスカウトアイコンで、特定の都道府県に赴くことで転生選手を発見できることがある。 |
| **履歴書の使用** | 「新入生の履歴書」アイテムを使い、確実に特定の選手を入部させる（DLC等の特殊履歴書）。 |

### 転生選手のメリット
- 初期能力が非常に高い。
- 強力な[特殊能力（金特など）](/wiki/card-effects)を最初から所持していることが多い。

出典: [appmedia.jp](https://appmedia.jp/pawapuro2026-2027/), [game8.jp](https://game8.jp/eikan-nine/)

> 実践への活かし方: 3年縛りでは初年度の3年生が引退した直後の「秋の大会」が最大の鬼門です。この大会を勝ち抜くため、即戦力となる転生エース投手（または強力な捕手）を初期設定で引き当てることが攻略の第一歩となります。

## 優勝旗の恩恵

[夏の甲子園や春の甲子園](/wiki/tournaments)で優勝すると、「優勝旗」を獲得できます。

![優勝旗イメージ (出典: https://img.game8.jp/12424056/94eac0f27c9e2dcaa1843ffd3a66e8e2.png/thumb)](/images/other-systems/94eac0f27c9e2dcaa1843ffd3a66e8e2.png)

| 優勝旗の仕様 | 詳細 |
|---|---|
| **所持期間** | 次の同大会が開催される直前まで（例：夏優勝なら翌年の夏前まで） |
| **発動条件** | 所持している期間中、**「白マス」に止まる** |
| **効果（ランダム）** | 体力回復、テンションUP、**練習効率UP**、特殊能力の習得 など |

出典: [nijiholo5koshien.com](https://nijiholo5koshien.com/), [game8.jp](https://game8.jp/eikan-nine/)

> 実践への活かし方: 優勝旗を持っている期間は、白マスが実質的に青マス以上の価値を持つボーナスマスに変化します。[マス優先度](/wiki/board-squares)の常識が覆るため、積極的に白マスを踏んでチームを強化しましょう。

## アプデ内容・DLC・不具合情報への注意

パワプロシリーズ（特に栄冠ナイン）は、発売後に大規模なアップデートやDLC追加が行われるのが通例です。

| 項目 | 3年縛りプレイへの影響 |
|---|---|
| **不具合修正パッチ** | 進行不能バグや戦術バランス（盗塁成功率など）がサイレント修正されることがあります。常に最新パッチを適用してプレイしてください。 |
| **DLC・データ更新** | 実際のプロ野球のペナントレース結果を反映し、転生選手の能力や所持特能が更新されることがあります。攻略サイトの初期データと異なる場合があるため注意。 |
| **コラボ履歴書** | にじさんじコラボなど、特定のDLCやパス購入特典として、強力なオリジナル選手を呼べる「履歴書」が配布されることがあります。 |

出典: [konami.com](https://www.konami.com/pawa/), [famitsu.com](https://www.famitsu.com/)

> 実践への活かし方: バランス調整パッチがあたると、今まで通用していた「転がせ一択」「盗塁連発」などの戦術が突然効かなくなることがあります。公式のアップデート履歴は必ずチェックするようにしましょう。
