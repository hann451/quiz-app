## 年間確定イベント日程一覧

栄冠ナインでは、毎年決まった日付に特定のイベントが発生します。これらの日付を把握し、進行アイコンを調整することが攻略の第一歩です。
※ 本ページは2026-2027版を主対象としています。

<details>
<summary><strong>春〜夏の確定イベント一覧（4月〜8月）</strong></summary>

| 日付 | イベント名 | 効果・内容 |
|---|---|---|
| 4/1 | 進級 | 全員が進級。停止すると全員練習効率小アップ |
| 4/8 | 入学式 | 新入生が入部。校名・都道府県・年代などの変更が可能 |
| 5/7(1年目のみ) | アイテム入手イベント(2026-2027新要素) | ミートバット+対ピンチの本を入手 |
| 5/26(1年目のみ) | アイテム入手イベント(2026-2027新要素) | スポンジとバケツ+雪かきスコップ×3入手（旧作「雪かき」から名称変更） |
| 6/11〜6/17 | 勉強イベント(白マス/低確率ランダム) | 「練習こそ大事」選択→全員練習効率中アップ(対象信頼度小ダウン等)。「全員で勉強会」選択→信頼度小アップ等 |
| 6/26〜7/2 | 技術指導イベント(青マス/低確率ランダム) | 特能や能力経験値アップ。赤特消去（打撃指導で三振削除等） |
| 7/2 | 夏の都道府県大会一回戦 | 開幕 |
| 7/7 | 七夕(確定発生) | 選択肢で効果変化（「個別練習経験値小アップ」「学力小アップ」等） |
| 7/21〜7/24(1年目のみ) | 校長イベント | 機材交換券を1回もらえる |
| 7/21〜7/30 | 甲子園インタビュー(青マス/甲子園出場決定後) | 選択肢に応じた経験値アップ、条件を満たす選手にランダムで青特・金特付与 |
| 7/25〜7/29 | 夏合宿 | 合宿。特能取得チャンス |
| 8/2 | 夏の甲子園組み合わせ抽選会 | — |
| 8/7〜8/8 | 夏の甲子園一回戦 | 停止すると全員練習効率小アップ |
| 8/10 | 特訓マス発生日(地域A) | 対象: 北海道、岩手県、宮城県、山形県、福島県（+長野県説あり）。80%特訓マス3〜4マス出現 |
| 8/15 | 特訓マス発生日(地域B) | 対象: 青森県・秋田県 |
| 8/21 | 特訓マス発生日(地域C) | 対象: 上記以外の都道府県 |
| 8/12 | 甲子園2回戦(8/11)敗退時の予備日 | 8/11に敗退時、8/12に特訓マス発生の報告あり |
| 8/27 | 日本代表候補招集イベント | 選出されなければ練習効率中アップ。選出時は9/6に結果判明 |

</details>
