## 育成方針の基本と進行アイコン出現率

栄冠ナインでは、毎月「育成方針」を変更することで、出現する「練習アイコン」の種類や選手の成長傾向をコントロールできます。

育成方針(バランス/打撃力重視/機動力重視/守備・投手力重視)によって各系統の出現率が変わります（練習系アイコン全体で約75%、その他イベント系で約25%が抽選される傾向）。打撃重視なら打撃系、投手・守備重視なら守備系アイコンが出やすくなります。

## 3年縛りでの学年別育成計画の定石

3年縛りにおける、複数サイトで概ね共通している育成方針の定石です。

### 基本方針（2026-2027版）
| 項目 | 内容 |
|---|---|
| チーム方針 | 1〜2年目夏まで機動力重視 → 2年目秋から守備・投手力重視 |
| マス優先度 | 青 > 白 > 黄 |
| キャプテン優先度 | ごくふつう > やんちゃ > したたか |
| ショップ優先度 | 仮設シャワー > むにむにボール > ストップウォッチ > ティー > その他 |
| コンバート方針 | 守備力の高い選手を二遊間に配置 |

### 学年別育成計画
| 学年 | 重点方針 |
|---|---|
| **1年目** | 強い一年生は即スタメン起用。内野手は守備・捕球優先、外野手は走力優先。投手は最低限スタミナ・制球優先で、先発は能力優先で選出。5月頃に守備位置調整、6月頃に弾道1→2。育成方針は「守備・投手力重視」。合宿には必ず参加。年間5勝を目標にグラウンドレベルを上げる。 |
| **2年目** | 投手は球速150km/h・スタミナA目標。野手は守備の伸ばし継続。占い師で性格変更(内気・お調子者を増やす方針)。日本代表選出で金特狙い。スカウトは代打・代走要員の補強。 |
| **3年目** | 育成方針を「打撃力重視」に切替。投手を最強化(球速160km/h、コントロールS目標)。特能本・アイテムで強化。夏の甲子園優勝を最終目標とする。 |

## ポジション別育成目標（シカダ式）

**野手ポジション別育成目標**
| ポジション | 目標能力値 | 優先順位 |
|---|---|---|
| 一塁手 | 4AAADCC | ミート→パワー→弾道→捕球→走力 |
| 二塁手 | 2AEADBC | 走力→ミート→守備→捕球 |
| 三塁手 | 2AEABCC | 走力→ミート→肩→捕球 |
| 遊撃手 | 2AEABBB | 走力→ミート→守備→肩→捕球 |
| 捕手 | 2AEABCB | 肩→捕球→走力→ミート |
| 外野手 | 2AEACCD | 走力→ミート→肩 |

**投手育成手順**
1. 任意の変化球を変化量5まで伸ばす（球種は問わない）
2. 3球種になるまで変化球を習得
3. 2年秋(世代交代)までに基礎ステータス「150DD総変化量10」を目安に育成
4. その後「155BB&総変化量10」を目指す
5. 大会がある月(7〜11月、3月)は変化量以外の練習を優先
6. 優先度: 変化量(決め球5〜6・その他2〜3) > コントロールD > 球速150 > スタミナD
7. 余裕があれば4球種&コンBを目標に、最終的に160SS総変13程度を目指す

## 投球フォームによる違い

### 能力・査定への数値補正は存在しない

投球フォーム（オーバースロー / スリークォーター / サイドスロー / アンダースロー）によって、**球速・コントロール・スタミナ・変化量などの能力値に補正がかかることはありません**。どのフォームで投げても変化量は同じで、選手の査定にも影響しません。

「クロスファイヤーはスリークォーターと相性が良い」といった話がありますが、これは**見栄えの問題であり数値上の相性ではありません**。特殊能力の効果はフォームに関係なく一律に発動するため、**育成方針をフォームに合わせる必要はありません**。

### 実際に差が出るポイント

| 要素 | 内容 |
| --- | --- |
| **投球動作の速さ** | フォームによってリリースまでの所要時間が異なる。1秒を切るものから3秒以上かかるものまで幅がある |
| **リリースポイント** | ボールが放たれる高さ・横位置が変わり、打者から見た球筋の見え方が変化する |
| **自操作時の体感** | サイドスロー・アンダースローは球種の判別がしづらく、タイミングを外しやすい |

| フォーム | リリースポイント | 球筋の見え方 |
| --- | --- | --- |
| オーバースロー | 頭上付近の高い位置 | 上からの角度がつく標準的な球筋。縦の変化球の落差が視覚的に強調される |
| スリークォーター | 肩口の斜め | やや斜めの軌道。癖が少なく扱いやすい |
| サイドスロー | 腰の高さの真横 | 横から入る角度が強く、横変化球の軌道が大きく変わって見える |
| アンダースロー | 地面に近い極めて低い位置 | 下から浮き上がるような球筋。緩急が効きやすく見える |
| 固有フォーム（プロ選手など） | 選手ごとの専用モーション | タメや二段モーション風の動きを持つものがあり、動作時間が長いフォームは打者のタイミングを崩しやすい |

### 【参考】アンダースローは成績が悪いという統計的観察

過去40年分・約130名の投手データを集計した個人検証では、**オーバースロー→スリークォーター→サイドスロー→アンダースローの順に成績が悪化する傾向**が観察されたという報告があります。検証者自身が「詳細な検証はしていない」と断っており、能力値補正が存在しないこととは矛盾しませんが（自動試合での打たれやすさの差である可能性がある）、**アンダースローの投手をエースに据える場合は頭の片隅に置いておく価値はあります**。

## 注目選手・なりきりプレイと試合経験値の仕様

**【重要】「経験値1.4倍〜2.0倍ボーナス」は誤り（俗説）です**
旧版などで言われていた「注目選手に設定すると試合経験値が1.4〜2.0倍になる」という固定倍率のボーナスは確認されていません。
実際の試合経験値は、**「試合中に出した指示の回数」**と**「試合に出場したかどうか」**の積み上げで決まります。指示を出す機会（自操作の機会）が多い選手ほど結果的に多くの経験値を獲得できる仕組みです。

### 今作の試合形式（アクション試合・なりきりプレイ）
今作（2026-2027版）では、従来の戦術試合に加えて「アクション試合」が選べます。
アクション試合では「なりきりプレイ（注目選手1人を操作）」と「チームプレイ（全員を操作）」が選択でき、操作頻度を「多い」に設定すると自操作の機会が増え、より多くの指示（経験値）を稼ぐことが可能になります。

### 注目選手の選び方の定石
1. **天才肌の選手を優先**: 固有戦術「急成長」（経験値200%）や「才能開花」を確実に使える。
2. **内気の選手（特に3年生）**: 任意のタイミングで「魔物」を使用できる。
3. **育成したい投手を選ぶ（経験値稼ぎ）**: 投手は野手より圧倒的に指示を出す機会が多く、変化球などの経験値は練習だけでは不足しがちです。余裕のある練習試合や格下戦では投手を注目選手にして指示回数を稼ぐのが定石です。
4. **打撃力の高い選手**: 野手を選ぶ場合、打席数が多くなりやすく、指示を出せる回数が増えるため経験値を稼ぎやすい。
5. **赤特リスクに注意**: 自操作していない場面で勝手に赤特が付くこともあるため、注目選手（なりきりプレイ）は必ず得をするわけではない点に注意が必要です。

### パリコレ（控え選手の底上げ）
試合終盤の大差リード時に、控え選手を大量投入して「出場扱い」にし、試合後の経験値を稼ぐテクニックです。
今作では代打・代走の場合、単に交代するだけでなく**【1打席の経過】**が必要になりました（交代連打による経験値稼ぎは不可）。交代しすぎると戦力が落ちて逆転されるリスクがあるため、点差に十分な余裕がある時のみ実行してください。
