## 進行アイコン（カード）の仕様と基礎経験値

栄冠ナインでは進行アイコンの数字の数だけマスを進みます。数字が大きいほど1回あたりの獲得経験値が増えますが、イベントマスに止まる機会が減るトレードオフがあります。

## マスの種類と優先度

| マスの種類 | 効果詳細 | 優先度目安 |
|---|---|---|
| **青マス** | 良質なイベントが発生。コイン入手や特殊効果が多い | 最優先級 |
| **白マス** | ランダムでイベント発生(吉凶あり)。練習試合も白マスから発生 | 中 |
| **黄マス** | 選択した練習系進行アイコンの基礎経験値の0.75倍を追加ボーナス。他アイコンで踏むと白マス相当扱い | 高 |
| **赤マス** | マイナスイベント発生。基本的に避けるべき | 最低 |
| **緑マス** | 練習に参加した選手優先で体力回復 | 高(体力が低い時) |
| **特訓マス** | 特殊能力取得のチャンス。最優先で踏むべきマス | 最優先 |

## 練習効率アップと経験値計算

- 練習効率アップ: 小アップ(約2倍)、中アップ(約4〜5倍)、大アップ(約6倍)。小ダウン(約0.8倍)、ダウン(約0.6倍)。
- 経験値の計算式(推定): `練習経験値 = (基礎値 × グラウンド補正 × 天候補正) × 体力補正 × 練習効率補正`
- グラウンド補正: グラウンドLv1で1.005倍、Lv99で1.495倍。2026-2027版では評判「超名門」時に上限122まで解放されます。
- 天候補正: 晴れ・曇り=1.665倍、雨・雪=1.0倍。
- 体力補正: 体力が最大(5)であれば補正なし(1.0倍)、体力が低いほど経験値が減少。

| ■ 基本仕様 |  |  |  |  |  |
|---|---|---|---|---|---|
| 基本仕様 | 「ならずもの」は卒業生（OB）の就職先の一つです。ならずもののマスに止まると【手持ちの進行アイコンがすべて入れ替わる】効果が発生します。この中核の仕組みは旧版どおり正しい内容でした。 |  |  |  |  |
| 出現の仕組み（訂正） | ならずものはマップ上に【キャラクターマス（OBマス）】として登場し、そのマスに止まることで発動します。旧版の「白マスを踏むと発生する」という説明は誤りです。 |  |  |  |  |
| 手札は5枚固定ではない（重要な訂正） | 旧版は「手札5枚がすべて入れ替わる」としていましたが、手札の枚数は学校の評判によって変わります。評判が1段階上がるごとに1枚増え、最高ランクの超名門では最大9枚になります。枚数が多いほどシャッフルで失うものも増えるため、評判が高いほどリスクは大きくなります。 |  |  |  |  |

| 合宿の日付（訂正） | 旧版は仕込みの起点を「6/25頃 / 11/10頃」、合宿直前を「7/20頃 / 12/5頃」としていましたが、合宿の提案日は6月20日と11月10日、合宿の開催は7/25〜7/29と12/10〜12/14です。仕込み期間と回避すべき期間の日付が実際とずれていました。 |  |  |  |  |
