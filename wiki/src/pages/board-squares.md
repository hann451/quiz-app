## マスの種類と効果一覧

栄冠ナインの進行画面は「すごろく」形式になっており、止まるマスの色によって発生するイベントが大きく異なります。どの色のマスを踏むかで育成効率が大きく変わるため、進行アイコンの使い方と合わせて理解しましょう。

![マス一覧イメージ (出典: https://img.game8.jp/10278503/c442dfc3e6e90b3a140f05eada03f20e.png/show)](/images/board-squares/c442dfc3e6e90b3a140f05eada03f20e.png)

| マス色 | 効果 | 発生内容の例 |
|:---:|---|---|
| **青マス** | **良いイベント確定** | 練習効率アップ、赤特消去（技術指導）、テンションUP、体力回復、能力値直上げ |
| **黄マス** | **経験値ボーナス** | 練習アイコンで止まると、基礎経験値に応じたボーナス加算。大きい数字ほど得 |
| **白マス** | **ランダムイベント** | 良いイベント(練習効率UP等)も悪いイベント(ケガ等)も発生し得る |
| **緑マス** | **体力回復** | 選手の体力が回復する。ケガ防止に有効 |
| **赤マス** | **悪いイベント** | テンション低下、体力減少、赤特付与などマイナスイベントが発生 |

出典: [appmedia.jp](https://appmedia.jp/pawapuro2026-2027/), [kamigame.jp](https://kamigame.jp/)

### マスの優先度

基本方針は **青 ＞ 黄 ＞ 白 ＞ 緑 ＞＞ 赤（回避）** です。

| 優先度 | マス色 | 理由 |
|:---:|:---:|---|
| **1位** | **青** | 良いイベント確定。赤特消去・練習効率UP・テンションUP等のリターンが高い |
| **2位** | **黄** | 練習ボーナスが安定。大きい進行アイコンで踏めば大量の経験値を稼げる |
| **3位** | **白** | ランダムのため当たり外れがあるが、良いイベントも十分狙える |
| **4位** | **緑** | 体力回復は有用だが、育成への直接貢献は小さい |
| **回避** | **赤** | マイナスイベントしか起きない。進行アイコンで避けるべき |

出典: [game8.jp](https://game8.jp/eikan-nine/), [note.com](https://note.com/)

> 実践への活かし方: 進行アイコンを選ぶ際は、まず青マスに止まれるかを確認し、次に黄マスを狙います。赤マスが近い場合は小さい数字のアイコンで手前に止まり、赤マスを飛び越えられる大きい数字が来るまで待ちましょう。

## 練習アイコンと経験値の仕組み

進行に使う「練習アイコン」の種類と数字によって、獲得できる経験値が決まります。

![練習アイコンイメージ (出典: https://img.game8.jp/12643542/118b78c3775d296c010266199cf04e43.webp/show)](/images/board-squares/118b78c3775d296c010266199cf04e43.webp)

### 練習アイコンの基礎経験値

| アイコン種別 | 上昇する能力 | 基礎経験値(目安) |
|---|---|:---:|
| **特打(バッティング)** | ミート・パワー・弾道 | 約100 |
| **特守(ノック)** | 守備・捕球・送球 | 約100 |
| **走り込み** | スタミナ・走力 | 約80 |
| **筋トレ** | パワー・肩力 | 約80 |
| **変化球** | 変化球経験値 | 約80 |
| **総合練習** | **全能力+20** (投手:合計約140 / 野手:合計約120) | 各能力20 |
| **他校調査** | 練習効率小UP＋試合時効果 | 固定1マス進行 |

※総合練習は全能力を均等に伸ばせるため、育成初期や伸ばしたい能力が定まっていない時に有効です。

出典: [note.com](https://note.com/), [appmedia.jp](https://appmedia.jp/eikan_nine/)

### 黄マスでの経験値ボーナス

黄マスに止まると、使用した練習アイコンの基礎経験値に対してボーナス値が加算されます。

| 条件 | 効果 |
|---|---|
| 黄マスに止まる | 基礎経験値 × マスの日数 × 0.75 がボーナスとして加算 |
| 練習効率UP(小) | 経験値 **2倍** |
| 練習効率UP(中) | 経験値 **4倍** |
| 練習効率UP(大) | 経験値 **6倍** |

出典: [note.com](https://note.com/)

> 実践への活かし方: 「練習効率UP」が発動しているタイミングで、数字の大きい練習アイコン(4や5)を黄マスに止まるよう使うと、1回の練習で通常の何倍もの経験値を獲得できます。効率UPの持続は次の練習1回分（観戦なら2回分）のみなので無駄にしないよう注意しましょう。

## 他校調査マスの使い方

パワプロ2024以降で追加された進行アイコンです。進行距離は固定1マスですが、練習効率アップと試合の勝率アップという2つの効果があります。

![他校調査イメージ (出典: https://img.game8.jp/12424056/94eac0f27c9e2dcaa1843ffd3a66e8e2.png/thumb)](/images/board-squares/94eac0f27c9e2dcaa1843ffd3a66e8e2.png)

| 項目 | 内容 |
|---|---|
| **進行距離** | 固定1マス |
| **効果①** | 選手全員の練習効率が小アップ |
| **効果②** | 調査対象の高校との試合で有利になる（相手能力低下等） |
| **効果持続** | 新入生入学(4月)または3年生引退(7月)まで持続 |
| **最適な使用タイミング** | **公式戦の対戦相手が決定した後** |

### なぜ「対戦相手決定後」が有効なのか

他校調査は調査した高校との試合で勝率が上がる効果があるため、組み合わせ抽選会で対戦相手が決まった直後に使用するのが最も効率的です。対戦相手が未定の段階で使っても、試合での恩恵を受けられない可能性があります。

出典: [appmedia.jp](https://appmedia.jp/pawapuro2026-2027/)

> 実践への活かし方: 他校調査アイコンは「青マスに止まりたいけど大きい数字しかない」場面で1マス調整するのにも便利です。公式戦前に使えば一石二鳥です。

## 特訓マスで出やすい特殊能力

特訓マスではランダムに選ばれた選手1人に特殊能力取得チャレンジが発生します。成功すると青特を獲得でき、信頼度も上昇します。

![特訓マスイメージ (出典: https://img.game8.jp/12641762/ffae1072a6f2aee3b6f58d02553a3018.webp/show)](/images/board-squares/ffae1072a6f2aee3b6f58d02553a3018.webp)

| 特殊能力 | 対象 | 狙い方・備考 |
|---|---|---|
| **内野安打◯** | 野手 | ダッシュ、インターバル走等の走力系アイコンと関連。戦術「転がせ」Lv6条件 |
| **パワーヒッター** | 野手 | 特打、ダンベル等の打撃系アイコンと関連 |
| **ムード◯** | 野手 | 守備連携、アロマテラピー等のカードから習得可能。チーム全体にバフ |
| **キャッチャー◯〜A** | 捕手 | 捕手の特訓で重点的に狙う。試合の勝敗に直結する重要特能 |
| **各種投手特能** | 投手 | ピンチ◯、奪三振、対左打者◯など。投手向けの練習アイコンで狙う |

※特訓パネルの☆数が多いほど成功確率が高くなる傾向があります。

出典: [game8.jp](https://game8.jp/eikan-nine/), [gamerch.com](https://gamerch.com/pawapuro/)

> 実践への活かし方: 特訓マスで狙いたい能力がある場合は、関連する練習器材を事前にショップで入手しておくと、対応するアイコンが出やすくなります。

## 合宿マスとショップアイテムの優先度

合宿（夏合宿・冬合宿）は集中的に育成ができる期間です。合宿前に「戦績ポイント」でショップから器材を購入しておくと、練習効率がさらに向上します。

![合宿ショップイメージ (出典: https://img.game8.jp/12641762/ffae1072a6f2aee3b6f58d02553a3018.webp/show)](/images/board-squares/ffae1072a6f2aee3b6f58d02553a3018.webp)

### ショップアイテム優先度ランキング（1000ptクラス）

| 優先度 | アイテム名 | 効果 | おすすめ理由 |
|:---:|---|---|---|
| **★★★** | **むにむにボール** | 変化球(投)・パワー(野)の経験値UP | 投手・野手両方に効果があり汎用性が最も高い |
| **★★★** | **仮設シャワー** | 体力回復＋「1マス確定」効果 | 進行アイコンの調整（赤マス回避等）に非常に便利 |
| **★★☆** | **ストップウォッチ** | 走力の経験値UP | 走力育成＋合宿で「内野安打◯」を狙えるアイコンと好相性 |
| **★★☆** | **ティー** | ミート・パワーの経験値UP | 打撃育成の基本。合宿で強力な打撃特能を狙うためにも重要 |
| **★☆☆** | **アロマグッズ** | テンション維持＋ムード◯獲得チャンス | 合宿で「ムード◯」取得を狙える点が優秀 |
| **★☆☆** | **ノックバット** | 守備力の経験値UP | 守備育成が必要な場合に優先 |

出典: [game8.jp](https://game8.jp/eikan-nine/), [appmedia.jp](https://appmedia.jp/pawapuro2026-2027/)

### 購入の基本戦略

1. **序盤（戦績ポイントが少ない時）**: むにむにボール → 仮設シャワー の順に1000pt器材を揃える
2. **中盤以降**: 育成方針に合わせてストップウォッチ・ティーなどを追加購入
3. **器材が揃った後**: **「器材お楽しみ交換券」** で2000ptクラスの上位器材を狙うのが最も効率的

> 実践への活かし方: 合宿前には「スケジュール変更手帳」を使って手持ちの練習アイコンを調整し、習得させたい能力に対応するカードを温存しておきましょう。合宿中は進行距離が短いため、小さい数字のアイコンでも十分に活用できます。
