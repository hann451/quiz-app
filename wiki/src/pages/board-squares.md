## 進行アイコン（カード）の仕様と基礎経験値

栄冠ナインでは進行アイコンの数字の数だけマスを進みます。数字が大きいほど1回あたりの獲得経験値が増えますが、イベントマスに止まる機会が減るトレードオフがあります。

## マスの種類と優先度

| マスの種類 | 効果詳細 | 優先度目安 |
|---|---|---|
| **青マス** | 良質なイベントが発生。コイン入手や特殊効果が多い | 最優先級 |
| **白マス** | ランダムでイベント発生(吉凶あり)。練習試合も白マスから発生 | 中 |
| **黄マス** | 選択した練習系進行アイコンの基礎経験値の0.75倍を追加ボーナス。他アイコンで踏むと白マス相当扱い | 高 |
| **赤マス** | マイナスイベント発生。基本的に避けるべき | 最低 |
| **緑マス** | 練習に参加した選手優先で体力回復 | 高(体力が低い時) |
| **特訓マス** | 特殊能力取得のチャンス。最優先で踏むべきマス | 最優先 |

### 黄マス（練習効率アップマス）の正確な仕様

> [!IMPORTANT]
> 従来「0.75倍」説と「約1.3倍」説が混在していましたが、**両方とも正しく、測り方が違うだけ**です。仕様としては **0.75倍の追加加算** が正確で、「約1.3倍」は練習効率アップが乗った状態での実測比率です。下の計算例を参照してください。

#### 仕様（加算の仕組み）

| 項目 | 内容 |
| --- | --- |
| **効果** | 直前に使用した練習進行アイコンの **基礎経験値 × 0.75** を追加経験値として加算 |
| **カードの数字との関係** | 進行アイコンの数字（日数）の分だけ追加経験値が増える。数字5なら「基礎経験値 × 0.75 × 5」 |
| **補正を受けない** | 黄マスの追加分は **グラウンドレベル・練習効率・天候・体力の影響を一切受けず、常に基礎経験値の0.75倍で一定** |
| **個別練習には乗らない** | 個別練習（サブメニューでの追加練習）の経験値は増えない |
| **練習系アイコン以外は無効** | 紅白戦・観戦などの非練習アイコンで踏むと白マス扱いになる |

#### 計算例（なぜ「1.3倍」に見えるのか）

基礎経験値167の「特打」を進行4で使い、グラウンドLv99（1.49倍）・体力0（0.82倍）・雨（0.6倍）・練習効率4倍の条件で黄マスに止まった場合:

```
通常部分: 167 × 1.49 × 0.82 × 0.6 × 4.00 = 484
黄マス加算: 167 × 0.75 = 125（補正を受けない固定値）
合計: 484 + 125 = 609
```

→ 実効倍率は 609 ÷ 484 ≒ **1.26倍**。これが「約1.3倍」と報告されてきた数字の正体です。
逆に補正が何もかかっていない状態なら 1 + 0.75 = **1.75倍**になります。
**練習効率が高いほど黄マスの相対的な旨みは下がる**という点が実戦上の重要な結論です。

#### 実戦での使い方

- 黄マスに止まる日は **数字の大きい（4〜5）練習アイコン** を使う。追加経験値がそのまま日数倍される
- **基礎経験値の高いアイコン**（総合練習・特打・特守・2000P器材アイコン）と合わせるとさらに効果的
- 逆に、アイドルイベント等で練習効率が既に4〜6倍になっている日は、黄マスの上乗せは相対的に小さい。効率アップは特訓マスや強力なアイコンに回したほうがよい
- **紅白戦は黄マスの恩恵を受けない**（白マス扱い）

### 夏の隠し特訓マス（発生日×都道府県グループ）
自校の所在地（都道府県）に応じて、夏の特定の日に「隠し特訓マス」が出現する可能性があります。

| 発生日 | 対象数 | 対象の都道府県 | 備考 |
|---|---|---|---|
| **8月10日** | 6 道県 | 北海道 / 岩手県 / 宮城県 / 山形県 / 福島県 / 長野県 | 北日本と長野。夏休みが短めの地域。 |
| **8月15日** | 2 県 | 青森県 / 秋田県 | 東北北部の2県のみ。 |
| **8月21日** | 39 都府県 | 上記8道県以外のすべて | 標準グループ。全国の大多数がこちら。 |

- **発生条件**: 夏の甲子園に出場していない場合、または **【出場したが途中で敗退した場合】** にも発生します。（※8/11の2回戦敗退時に8/12に発生したケースも報告あり）。旧版の「出場していないことが絶対条件」は誤りです。
- **発生効果（訂正）**: 該当日に止まると、約80%の確率で「3〜4日間のマスが特訓パネルに変わる」、残り約20%で「3〜4日間が緑パネル（回復マス）に変わる」という**二者択一**です。旧版にあった「特訓マス＋練習効率が大アップ＋全員の体力回復が同時に起きる」は誤りです。
- **マス調整のセオリー**: 地方大会敗退後、進行カードの数字を計算し、自校のグループに対応する発生日にピッタリ止まれるよう調整するのが定石です。

## 練習器材の入手・耐久度・グラウンドレベル寄与

### 器材は「交換券」で入手する

器材は個別に価格が設定されて売られているのではなく、**器材交換券**を購入・入手して使う方式です。交換券は**使うまで効果が発揮されない**ので、入手したらアイテム欄からすぐに使用してください。

| 入手方法 | 詳細 |
| --- | --- |
| 戦績ショップ | 試合で通算5勝するごとに利用可能。1000P / 2000P の交換券、および1600Pの「器材お楽しみ交換券」 |
| OB「ミゾット社員」マス | ランダムな器材交換券をくれるか、器材の耐久値を上げる |
| 公式戦初勝利など | ランダムな器材交換券をもらえることがある |
| 校長イベント（7/21〜7/24） | 1年目のみ・1回限定で器材お楽しみ交換券をもらえる |

### 最効率の集め方（戦績ポイント節約テクニック）

1. まず **1000Pの器材交換券**を普通に購入し、1000P器材を全種そろえる
2. そろえ終わったら **1600Pの「器材お楽しみ交換券」** を購入して使う
3. お楽しみ交換券は「まだ設置していない器材」からランダムで選ばれるため、1000P器材が全部埋まっていれば **確定で2000P器材** が手に入る

→ 2000P器材を1個あたり **実質400P安く** 入手できます。

> [!NOTE]
> **グラウンドレベルの伸びだけを見るなら1000P器材のほうがコスパが良い**という点に注意。1000P器材は約3%、2000P器材は約4%しかレベルが上がらないため、同じ2000Pを使うなら1000P器材2個のほうが得です。2000P器材の価値は、レベルではなく **対応する上位練習アイコンの基礎経験値の高さ** にあります。

### 土について

グラウンドレベルは **器材レベル + 土レベル** の合計です。土でもレベルは上がりますが、**耐久値が低くコスパが悪い**ため、器材を全部そろえてから購入するのがセオリーです。

### 耐久度と破損

| 項目 | 内容 |
| --- | --- |
| **確認方法** | 練習にカーソルを合わせたときのコメント右側、または「データ」→「アイテム・設備」画面（Rボタン） |
| **減り方** | 対応する練習アイコンを使用するたびに劣化する |
| **壊れると** | グラウンドレベルが下がり、その器材が必要な上位練習アイコンも進行カードに出現しなくなる |
| **経験値計算への影響** | 練習でレベルが下がった場合、その練習の経験値は **下がった後の数値** で計算される |
| **対策** | 壊れる前に予備の交換券を確保しておく。上限を維持したいなら土で余裕を持たせる |

> [!TIP]
> **序盤の裏技**: 器材は「設置した時にレベルが上がり、壊れた時に下がる」だけなので、序盤はあえて器材アイコンを使わずに温存すると、グラウンドレベルを高いまま維持できます。

### 3年縛りでの器材優先度

| 優先度 | 器材 | 理由 |
| --- | --- | --- |
| 最優先 | 仮設シャワー | 体力回復効果があり、かつほぼ壊れない |
| 高 | むにむにボール（握力強化） | 経験値効率が全器材中で最高。パワーも同時に付与 |
| 中〜高 | ストップウォッチ（ベースランニング） | 機動力重視だと壊れやすいが、盗塁+2・内野安打〇が強力 |
| 中〜高 | ティー（ティーバッティング） | 打撃力重視以外なら壊れにくく、アベレージヒッター等が狙える |
| 中 | ノックバット / ノックマシン | 特守の出現に必要 |

## 練習効率アップと経験値計算

- 練習効率アップ: 小アップ(約2倍)、中アップ(約4〜5倍)、大アップ(約6倍)。小ダウン(約0.8倍)、ダウン(約0.6倍)。
- 経験値の計算式(推定): `練習経験値 = (基礎値 × グラウンド補正 × 天候補正) × 体力補正 × 練習効率補正`
- グラウンド補正: グラウンドLv1で1.005倍、Lv99で1.495倍。2026-2027版では評判「超名門」時に上限122まで解放されます。
- 天候補正: 晴れ・曇り=1.665倍、雨・雪=1.0倍。
- 体力補正: 体力が最大(5)であれば補正なし(1.0倍)、体力が低いほど経験値が減少。
